# SCAR Frontend

Aplicación Angular 21 para **SCAR** (Sistema de Control de Actividades Realizadas).

## Requisitos

- Node.js 20+
- Yarn

## Desarrollo

```bash
yarn install
yarn start
```

Abre `http://localhost:4200`.

## Build

```bash
yarn build
```

## API backend

Por defecto el frontend usa la API en `http://localhost:8080`. Configura `src/environments/environment.ts` si necesitas otro origen.
